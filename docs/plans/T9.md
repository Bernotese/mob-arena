# T9 – HUD and config GUI (plan)

Read: SPEC 3, 10, 11; PLAN T9. Package `dev.mobarena.hud` (HUD) and `dev.mobarena.config` (GUI). No mixin. No client code.
Running game values: `ctx.config()` (snapshot). The GUI edits only `MobArenaConfig` (JSON model) and saves at once (SPEC 11).

## 1. Classes
| Class | Kind | Job |
|---|---|---|
| `TimeFormat` | pure | `mmss(long ticks)` → `44:59`, `h:mm:ss` if ≥ 1 h. Unit test. |
| `BossBarHud` | MC | One `ServerBossEvent` per team + one for lobby viewers (section 2). |
| `HudLine` | pure, record | `Component text, float progress, Color color` (`BossEvent.BossBarColor` [V]). |
| `HudOverrides` | MC | `set(TeamId, HudLine)`, `clear(TeamId)`. T7 calls it in `ARENA`/`SUDDEN_DEATH`. Override wins over the phase line. |
| `Titles` | MC | `show(player, title, subtitle, fadeIn, stay, fadeOut)`, `showAll(players, ...)`. Packets `ClientboundSetTitlesAnimationPacket`, `ClientboundSetTitleTextPacket` [V], subtitle packet. |
| `ActionBar` | MC | `send(player, Component)` → `ServerPlayer.sendOverlayMessage` [V]. |
| `ConfigStep` | pure | Per key: step, min, max. `int apply(int value, boolean right, boolean shift)`. Unit test. |
| `ConfigGui` | MC, `SimpleGui` 9x3 | Section 3. |
| `ConfigGuiHub` | MC | Open config GUIs; re-render all after each change (more admins). |

## 2. Boss bar
- Bar per team (`ServerBossEvent(uuid, name, color, BossBarOverlay.PROGRESS)` [V]); players of the team see only their bar. Lobby spectators see a third, neutral bar (phase + time only).
- Update every 20 ticks and on each phase change. `setName`, `setProgress(remaining / total)`, `setColor`.
- `JOIN` → `addPlayer`; `LEAVE` → `removePlayer`; `LOBBY.onEnter` → `removeAllPlayers` + `setVisible(false)`.

| Phase | Text (example) | Color | Progress |
|---|---|---|---|
| `LOBBY` | hidden | – | – |
| `PREP` | `Preparation – 44:59` | GREEN | phase time left |
| `WAVE_CONFIG` | `Wave setup – 2:59 – 3/4 ready` | YELLOW | phase time left |
| `ARENA` | T7 override: `Wave 2/3 – 12 mobs left – 14:32` / `Cooldown – 0:15` / `Finished – 9:41` | RED | wave time left |
| `SUDDEN_DEATH` | T7 override: `Sudden death – 40 mobs left – 9:12` | PURPLE | time left |
| `END` | `Team RED wins` / `Draw` | team color / WHITE | 1.0 |
