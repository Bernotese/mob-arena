# T8 – Results, sudden death, end (plan)

Read: SPEC 7.6, 8, 9; `docs/plans/T7.md` sections 1.4, 9. Package `dev.mobarena.result`. No mixin.
Config: read only `ctx.config()` (per-phase `MobArenaConfig.Snapshot`), e.g. `ctx.config().endScreenSeconds()`. Progress type: `core.TeamProgress(clearedWaves, killsInCurrentWave, ticks)`.

## 1. Classes
| Class | Kind | Job |
|---|---|---|
| `Outcome` | pure, sealed | `Running`, `Finished(long ticks)`, `Eliminated(TeamProgress p)`. |
| `Verdict` | pure, sealed | `Pending`, `Win(TeamId)`, `SuddenDeath`, `Draw`. |
| `WinResolver` | pure | `Verdict arena(Outcome red, Outcome blue)`, `Verdict suddenDeath(Outcome red, Outcome blue)`. Table in section 2. |
| `ResultTracker` | MC | Implements `ResultHooks` (put in ctx at `ARENA.onEnter`) and the T7 `BattleListener` (sudden death). Stores one `Outcome` per team. Sets `dirty`. |
| `ResultPhaseListener` | MC | At tick end, if `dirty`: run the resolver once. `Win`/`Draw` → store `ResultKeys.RESULT`, `GameManager.finish()`. `SuddenDeath` → `GameManager.enterSuddenDeath()`. |
| `SuddenDeath` | MC | `SUDDEN_DEATH` phase listener. Section 3. |
| `EndSequence` | MC | `END` phase listener. Section 4. |
| `ResultKeys` | MC | `Key<GameResult> RESULT`; `record GameResult(Optional<TeamId> winner, String reason)`. |

Same-tick rule: hooks only record. The resolver runs once per tick (`END_SERVER_TICK`). Thus two events in one tick give one verdict.

## 3. Sudden death flow
1. `ARENA.onExit` (T7) removes wave mobs. `SUDDEN_DEATH.onEnter`: new `ResultTracker` outcomes (both `Running`).
2. All team players: `SURVIVAL`, teleport to the own team spawn (eliminated players come back from the other arena), full health and food. Arenas are not repaired.
3. For each team: `ArenaBattle.startSuddenDeath(team, ctx, tracker)` (T7). One wave = all 3 enemy waves, countdown as normal, cooldown 0, max time `suddenDeathMaxTimeSeconds`, tag `n = 4`.
4. Tracker → resolver (`suddenDeath`) each dirty tick → `Win`/`Draw` → `GameManager.finish()`.
5. `SUDDEN_DEATH.onExit`: T7 stops the battles.

## 4. End sequence (`END`)
- `onEnter`: read `RESULT`. Title to all game players: `Team RED wins` (team color) or `Draw`; subtitle = reason (`All waves cleared`, `More progress`, `Sudden death`). Use T9 `Titles`.
- Fireworks: every 20 ticks for the first 5 s, one `FireworkRocketEntity(level, x, y, z, stack)` [V] above each online winner player (stack with `DataComponents.FIREWORKS`, team color). Draw: no fireworks.
- Chat summary: per team cleared waves, kills, time (`m:ss`).
- After `endScreenSeconds` (phase timer): `GameManager.endPhaseNow()` → `LOBBY`.
- `onExit`: clear inventories of all game players (incl. armor, offhand), clear effects. T2 teleports to the lobby, T4 clears backpacks, T5 deletes worlds (Q3).
- `/ma stop` during `END`: same exit path.
