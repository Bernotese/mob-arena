## 2. Test driver `/ma debug` (new package `dev.mobarena.debug`, T10 implementation task)
Only active with JVM property `-Dmobarena.debug=true` (GameTest and `runServer` dev config). Permission 4. All sub-commands also exist as a Java API (`DebugDriver`) so GameTests call them without parsing.
| Command | Effect |
|---|---|
| `kill <player> <entity> [n]` | Spawn n mobs at the player, kill each with `damageSources().playerAttack(player)` → real T6 attribution path. |
| `pool add <team> <entity> <n>` | Add to the pool directly (fast PREP). |
| `waves <team> <w1> <w2> <w3>` | Set the `WaveSetup` (`zombie:3,cow:1` per wave). |
| `clearwave <team>` | Kill all alive mobs of the current wave (generic kill) and empty the queue. |
| `down <player>` | Damage the player to death (real `ALLOW_DEATH` path). |
| `timer <seconds>` | Set the phase timer left. |
| `state` | Log one line `MOBARENA_STATE {json}`: phase, timer, teams, pool totals, plans, battle state per team, outcomes, verdict, open levels. Scripts and tests parse it. |

## 7. Open questions
- **Q1** May `runServer` dev runs use Carpet (dev only, never shipped)? Plan: yes.

### Decisions (orchestrator, 2026-11-07)
- Q1: yes, Carpet is OK as a dev-only runtime mod (`modLocalRuntime` or a manual jar in `run/mods`). It must not be in the release jar.
- Q2: no real-client bot. The user does the final manual check with a real client.
- Q3: yes, `/ma debug` stays in the release jar. It is off by default, needs `-Dmobarena.debug=true` and permission level 4.

### Note from T2 (orchestrator, 2026-11-07)
- `GameTestHelper.makeMockServerPlayerInLevel()` always reports creative mode, so mode-based rules (lobby, damage, guards) give wrong results. T2 replaced it with online test players that use real game modes and in-memory connections. Reuse that T2 helper in all GameTests.
- GameTests that change the `GameManager` singleton and wait for ticks must run in their own batch (T4 review note).
- Manual check with a real client: a ready click on slot 33 that ends WAVE_CONFIG closes the wave menu without an error (T6b review note).
