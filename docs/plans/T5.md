## 1. Facts found in the jars (read this first)
1. **Game rules per level work with Fantasy.** [V] `RuntimeLevel` overrides `getGameRules()`. If `mirrorOverworldGameRules` is `false`, Fantasy makes a new `GameRules` with defaults and then applies the `setGameRule(..)` values. Vanilla reads `KEEP_INVENTORY`, `MOB_GRIEFING` and `ADVANCE_WEATHER` from `ServerLevel.getGameRules()`. So these rules apply per level.
   - Exception: `ADVANCE_TIME` for clocks. `ServerClockManager.tick()` reads `MinecraftServer.getGlobalGameRules()`. Fantasy has its own per-level clock (`RuntimeClockManager`, `setShouldTickTime`, `setClockTime`). Use these for the arena time.
   - `/gamerule` commands change only the global rules. They do not change the game worlds.
2. **Weather is global.** [V] `ServerLevel.getWeatherData()` returns `MinecraftServer.getWeatherData()`. A level with `ADVANCE_WEATHER=false` still shows rain when the global weather is rain. So "no weather" needs a mixin (5.5).
3. **World spawn is global.** [V] `ServerLevel.getRespawnData()` returns `MinecraftServer.getRespawnData()`. A runtime level has no own spawn. T5 must find the spawn (4.3) and route respawns (5.6).
4. **Keep inventory on respawn depends on the respawn level.** [V] `Player.dropEquipment` reads the rule of the death level. `ServerPlayer.restoreFrom(old, keepAll)` reads the rule of the **new** level (`this.level()`). If a player dies in a team world and respawns in the lobby (rule off), the items are lost. So the respawn must go to a team world (5.6).
5. **Portals are hard-wired to vanilla keys.** [V] `NetherPortalBlock.getPortalDestination` picks `Level.NETHER` or `Level.OVERWORLD` by `level.dimension()` and calls `server.getLevel(key)`. `BaseFireBlock.inPortalDimension(Level)` allows portal lighting only if `dimension()` is `OVERWORLD` or `NETHER`. `EndPortalBlock.getPortalDestination` goes to `Level.END`. Fabric API has no portal event. So we need mixins (5.1–5.3).
6. **Seed.** [V] `RuntimeLevel.getSeed()` returns the config seed. `ChunkMap` uses `level.getSeed()` for `RandomState` and `createState` (terrain, biomes, structure placement). [U] `ServerLevel` also passes `WorldGenSettings.options()` (the server seed) to `StructureManager`/`StructureCheck`. Structure checks can use the server seed. Both teams get the same result, so it is fair. Test that villages generate and `/locate` works (test W3).
7. **Sun burn.** [V] `Mob.isSunBurnTick()` and `Mob.burnUndead()` are **private** (TECH.md did not say this). `@Inject` on a private method works. Only `Mob` calls them.
8. **MixinExtras** is available. [V] Fantasy itself uses `@WrapOperation` (`com.llamalad7.mixinextras`), and Fabric Loader ships it.
9. **The dragon fight works in a Fantasy level.** [V] The `ServerLevel` constructor makes an `EnderDragonFight` if `dimensionType().hasEnderDragonFight()`. `data/minecraft/dimension_type/the_end.json` has `"has_ender_dragon_fight": true`. So a Fantasy level with `BuiltinDimensionTypes.END` gets a dragon fight. Facts:
   - The fight data comes from `getDataStorage()` = `getChunkSource().getDataStorage()`. This is **per level**, so the RED and BLUE fights are separate.
   - `EnderDragonFight` (package `net.minecraft.world.level.dimension.end`; not `EndDragonFight`) has **no** `Level.END` key checks. `ServerLevel.tick` ticks it when the tick rate runs normally.
   - `init(level, seed, BlockPos.ZERO)` gets the **server** seed (`WorldOptions.seed()`), not the game seed. This changes only the gateway order. Both teams get the same order, so it is fair.
   - Fantasy does not touch the dragon fight (no reference in `RuntimeLevel`).
   - [U] The End terrain and the obsidian spikes use the level seed (`RuntimeLevel.getSeed()`). Test W13.
10. **End portal code is hard-wired to `Level.END`.** [V] `EndPortalBlock.getPortalDestination(level, entity, pos)`:
   - `isEnd = level.dimension() == Level.END`. Target key: `isEnd ? server.getRespawnData().dimension() : Level.END`. Target level: `server.getLevel(key)`; `null` -> no teleport.
   - To the End: spawn on `ServerLevel.END_SPAWN_POINT`, `EndPlatformFeature.createEndPlatform(..)`.
   - From the End, **players**: `return player.findRespawnPositionAndUseSpawnBlock(false, DO_NOTHING)`. So our respawn mixin 5.6 also routes the End exit. No death, no `restoreFrom`: the player keeps all items (normal teleport).
   - From the End, **other entities** (items, mobs): position = `server.getRespawnData().pos()` (the lobby spawn) + `entity.adjustSpawnLocation(..)`.
   - `EndPortalBlock.entityInside` shows the End credits only if `level.dimension() == Level.END`. In a team End this is false, so the player goes through without credits.
11. **End gateways need a fix.** [V] `TheEndGatewayBlockEntity.getPortalPosition` makes the exit (outer islands) only if `level.dimension() == Level.END`. Else it returns `null`. Without a mixin, gateways in the team End do nothing.
12. Other `Level.END` checks (no change needed) [V]: `Entity.canTeleport` and `ThrownEnderpearl.canTeleport` (special case End -> overworld), `FrostedIceBlock.tick`, `ChaseCommand`, `handleClientCommand` (advancement trigger after credits).

## 2. Classes
| Class | Type | Job |
|---|---|---|
| `WorldKind` | enum | `PREP_OVERWORLD`, `PREP_NETHER`, `PREP_END`, `ARENA`. Method `vanillaKey()` -> `Level.OVERWORLD` / `NETHER` / `END` / none. |
| `GameLevels` | static registry | `Map<ResourceKey<Level>, Entry(TeamId, WorldKind)>`. API: `teamOf(Level) -> Optional<TeamId>`, `kindOf(Level)`, `level(TeamId, WorldKind) -> ServerLevel`, `isGameLevel(Level)`, `isPrepLevel(Level)`, `isArena(Level)`. Fast lookup (mixins call it each tick). Also used by T3 (level -> team map). |
| `TeamWorlds` | record | Per team: the 4 `RuntimeLevelHandle`s (overworld, Nether, End, arena), `prepSpawn: BlockPos`, `ArenaLayout`. Stored in `GameContext` with key `TeamWorlds.KEY` (`Map<TeamId, TeamWorlds>`). |
| `PrepWorldManager` | `PhaseListener` | `onEnter(PREP)`: make 2 overworlds, 2 Nethers and 2 Ends, find spawns, teleport players. Writes `GameContext` prep levels. |
| `ArenaWorldManager` | `PhaseListener` | `onEnter(WAVE_CONFIG)`: make 2 arena levels, paste the template. (Early, so chunks are ready at `ARENA`.) |
| `WorldCleanup` | `PhaseListener` + hooks | `onEnter(LOBBY)` after a game, and `/ma stop`: teleport all players in game levels to the lobby, then `handle.delete()` for all 8 levels, then `GameLevels.clear()`. Also on `ServerLifecycleEvents.SERVER_STOPPING`. |
| `LevelFactory` | util | Builds the `RuntimeLevelConfig`s (section 3). Level ids: `mobarena:<team>_overworld`, `mobarena:<team>_nether`, `mobarena:<team>_end`, `mobarena:<team>_arena` (lower case team). |
| `TeamSpawnFinder` | util | Finds the spawn of a prep overworld (4.3). |
| `RespawnRouter` | util | `Optional<TeleportTransition> route(ServerPlayer)`. T5 handles `PREP`. T7 adds `ARENA` via a small hook interface (`RespawnRouter.register(Phase, fn)`). |
| `ArenaTemplate` | class | Loads `config/mob-arena/arenas/<name>.nbt` or uses `DefaultArenaBuilder`. Returns `ArenaLayout`. |
| `ArenaLayout` | record | `BlockPos teamSpawn`, `List<BlockPos> mobSpawns`, `List<BlockPos> waterSpawns`, `AABB bounds`. Used by T7. |

| `PortalLink` | pure logic | `kindFor(ResourceKey<Level> vanillaKey) -> WorldKind`: `NETHER` -> `PREP_NETHER`, `END` -> `PREP_END`, any other key -> `PREP_OVERWORLD`. The mixins ask vanilla which key it wants, then use the team level of that kind. Unit test. |

Use `Fantasy.openTemporaryLevel(Identifier, config)` (temporary: Fantasy deletes them on server stop) [V].

## 3. Fantasy configs [V names]
```java
long seed = ctx.seed();
var dims = server.getWorldGenSettings().dimensions();               // [V]
ChunkGenerator owGen = dims.get(LevelStem.OVERWORLD).orElseThrow().generator();  // [V]
ChunkGenerator netherGen = dims.get(LevelStem.NETHER).orElseThrow().generator(); // [V] works also if allow-nether=false
ChunkGenerator endGen = dims.get(LevelStem.END).orElseThrow().generator();       // [V]

RuntimeLevelConfig prep(ChunkGenerator gen, ResourceKey<DimensionType> type) {
  return new RuntimeLevelConfig()
    .setSeed(seed).setGenerator(gen).setDimensionType(type)     // BuiltinDimensionTypes.OVERWORLD / NETHER / END [V]
    .setMirrorOverworldGameRules(false)                          // own GameRules [V]
    .setMirrorOverworldDifficulty(true)
    .setGameRule(GameRules.KEEP_INVENTORY, true)
    .setShouldTickTime(true);                                    // normal day cycle
}
RuntimeLevelConfig arena() {
  return new RuntimeLevelConfig()
    .setGenerator(new VoidChunkGenerator(server))                // [V]
    .setDimensionType(BuiltinDimensionTypes.OVERWORLD)
    .setMirrorOverworldGameRules(false)
    .setGameRule(GameRules.KEEP_INVENTORY, true)
    .setGameRule(GameRules.MOB_GRIEFING, true)                   // SPEC 7.1: mobs can destroy the arena
    .setGameRule(GameRules.SPAWN_MOBS, false)                    // no natural spawns (name [V], effect [U])
    .setGameRule(GameRules.ADVANCE_WEATHER, false)
    .setShouldTickTime(false)
    .setClockTime(WorldClocks.OVERWORLD, 6000);                  // noon [U: value 6000 = noon in the clock]
}
```

## 4. Prep phase flow
1. `onEnter(PREP)`: make 6 levels, register them in `GameLevels`, put them in `GameContext`.
2. Find the spawn for each team overworld (4.3). Same seed -> same spawn for both teams.
3. For each team player: clear inventory, full health and hunger, survival, `teleport(new TeleportTransition(level, Vec3.atBottomCenterOf(spawn), Vec3.ZERO, 0, 0, TeleportTransition.DO_NOTHING))` [V constructor].
4. Generate the spawn chunks before teleport: `level.getChunk(x>>4, z>>4)` on the server thread (blocks the tick ~1 s). [U] If the delay is too long, use a ticket and teleport 1 tick later.

### 4.3 Spawn search (copy of vanilla `MinecraftServer.setInitialSpawn`) [V]
- `ChunkPos origin = gen.getOrigin(level.getChunkSource().randomState())`.
- Spiral over 11 x 11 chunks around `origin`. For each chunk: `PlayerSpawnFinder.getSpawnPosInChunk(level, chunkPos)` (public static). Use the first non-null result.
- Fallback: `origin.getWorldPosition()` with `level.getHeight(Heightmap.Types.WORLD_SURFACE, x, z)`.
- Per player (spawn radius like vanilla): `PlayerSpawnFinder.findSpawn(level, pos) -> CompletableFuture<Vec3>` (public). Optional. Version 1 can put all players on the same position.

## 5. Mixins (all in `dev.mobarena.mixin`, add to `mobarena.mixins.json`)
Each mixin has one comment line: owner `T5` and the reason.
**Rule (SPEC 3, decision Q1/Q2):** Nether and End portals work only in team prep levels. In all other levels (lobby, vanilla Nether/End, arenas) portals do nothing. This is true also when no game runs.

**5.0 `PortalBlockGuardMixin`** – portals do nothing outside prep levels.
- `@Inject(method = "entityInside", at = @At("HEAD"), cancellable = true)` on `NetherPortalBlock` and on `EndPortalBlock` (2 small mixin classes): cancel if `!GameLevels.isPrepLevel(level)`. [V] `entityInside` calls `Entity.setAsInsidePortal(..)`, so the portal process never starts.
- Shared helper for 5.1, 5.3, 5.7: `PortalKeys.vanillaKeyOf(ServerLevel)` returns `kind.vanillaKey()` for a team prep level, else the real `dimension()`. `PortalKeys.teamLevel(ServerLevel source, ResourceKey<Level> wanted)` returns `GameLevels.level(team, PortalLink.kindFor(wanted))`.

**5.1 `NetherPortalBlockMixin`** – team portal link.
- `@WrapOperation(method = "getPortalDestination", at = @At(value = "INVOKE", target = "Lnet/minecraft/server/level/ServerLevel;dimension()Lnet/minecraft/resources/ResourceKey;"))`: return `PortalKeys.vanillaKeyOf(level)`. This fixes both calls (source key choice and the `isNether` flag for the exit portal search).
- `@WrapOperation(... target = "Lnet/minecraft/server/MinecraftServer;getLevel(Lnet/minecraft/resources/ResourceKey;)Lnet/minecraft/server/level/ServerLevel;")`: if the source level is a team prep level, return `PortalKeys.teamLevel(source, key)`. Source level = first method argument (`@Local(argsOnly = true) ServerLevel level`).
- Teleport scale and exit portal search use the dimension types (overworld 1, Nether 8). This works without changes [V: `DimensionType.getTeleportationScale(from, to)`].

**5.2 `BaseFireBlockMixin`** – portal lighting.
- `@Inject(method = "inPortalDimension", at = @At("HEAD"), cancellable = true)` (private static): return `true` if `GameLevels.kindOf(level)` is `PREP_OVERWORLD` or `PREP_NETHER` (not `PREP_END`: vanilla does not allow it in the End either). Without it, flint and steel does not light a portal in team worlds [V].

**5.3 `EndPortalBlockMixin`** – team End link (fact 1.10).
- `@WrapOperation(method = "getPortalDestination", at = @At(value = "INVOKE", target = "Lnet/minecraft/server/level/ServerLevel;dimension()Lnet/minecraft/resources/ResourceKey;"))`: return `PortalKeys.vanillaKeyOf(level)`. So a team End counts as `Level.END` (`isEnd = true`), a team overworld as `Level.OVERWORLD`.
- `@WrapOperation(... target = "Lnet/minecraft/server/MinecraftServer;getLevel(Lnet/minecraft/resources/ResourceKey;)Lnet/minecraft/server/level/ServerLevel;")`: if the source is a team prep level, return `PortalKeys.teamLevel(source, key)`. Overworld -> `END` -> team End. Team End -> respawn key (lobby `OVERWORLD`) -> team overworld.
- `@WrapOperation(... target = "Lnet/minecraft/world/level/storage/LevelData$RespawnData;pos()Lnet/minecraft/core/BlockPos;")`: if the source is a team End, return the team prep spawn (`TeamWorlds.prepSpawn`). This is for non-player entities (fact 1.10). Players use 5.6.
- Players from the team End: vanilla calls `findRespawnPositionAndUseSpawnBlock`. Mixin 5.6 changes a non-game result to the team overworld spawn. A bed in the team overworld (or an anchor in the team Nether) is used as in vanilla.
- End credits: not shown in team Ends (fact 1.10). Open question Q8.

**5.4 `MobSunBurnMixin`** – no sun burn in arenas.
- `@Inject(method = "isSunBurnTick", at = @At("HEAD"), cancellable = true)` on `Mob` (private): `setReturnValue(false)` if `GameLevels.isArena(this.level())`.

**5.5 `LevelWeatherMixin`** – no weather in arenas.
- `@Inject(method = "canHaveWeather", at = @At("HEAD"), cancellable = true)` on `Level` [V: public, used by `isRaining()` and `advanceWeatherCycle()`]: return `false` for arena levels. Then the rain level of the arena stays 0, and vanilla sends no rain packets to that dimension.
- Note: `Level` is common code. The mixin is server-safe because `GameLevels` only has server levels.

**5.6 `ServerPlayerRespawnMixin`** – respawn in the team world (fixes fact 1.4).
- `@Inject(method = "findRespawnPositionAndUseSpawnBlock", at = @At("RETURN"), cancellable = true)` on `ServerPlayer` [V signature `(boolean, TeleportTransition$PostTeleportTransition) -> TeleportTransition`].
- If the player is in a running game and the result level is not a game level (no bed, or bed lost): replace it with `RespawnRouter.route(player)` (PREP: team overworld spawn). The End exit portal also calls this method (fact 1.10), so the End exit uses the same route. Beds and respawn anchors in team worlds keep working (vanilla result is a game level).
- Fabric alternative (no mixin): `ServerPlayerEvents.AFTER_RESPAWN` + teleport. **Do not use it**: the player respawns in the lobby first, so `restoreFrom` reads the lobby rule and the items are lost.

**5.7 `EndGatewayMixin`** – gateways in the team End (fact 1.11).
- `@WrapOperation(method = "getPortalPosition", at = @At(value = "INVOKE", target = "Lnet/minecraft/server/level/ServerLevel;dimension()Lnet/minecraft/resources/ResourceKey;"))` on `TheEndGatewayBlockEntity`: return `PortalKeys.vanillaKeyOf(level)`. Then the gateway finds or makes its exit on the outer islands, in the same level. No `getLevel` call, so no other change.

**5.8 Dragon kills** – no mixin. The Ender Dragon does not count as a kill: `ender_dragon` is in `mobBlacklist` (T6). The dragon fight itself needs no mixin (fact 1.9).

## 6. Default arena layout (`DefaultArenaBuilder`)
Center `C = (0, 64, 0)` in the void level. All sizes are constants in the class.
- Floor: disc radius 30 at `y = 63`, `stone` with random `andesite` / `cobblestone` (seeded). Layer below (`y = 62`): `bedrock` disc radius 31 (players cannot dig into the void).
- Wall: `barrier` ring radius 31 to 32, `y = 62..90`. Roof: `barrier` disc radius 32 at `y = 91`.
- Team spawn: `C` on top of a 5 x 5 `polished_andesite` pad.
- Cover: 8 pillars `stone_bricks` 2 x 2 x 4 at radius 14, every 45°. 4 low walls `cobblestone` 5 x 1 x 2 at radius 22, rotated 45° to the pillars.
- Water basin: 7 x 7, 3 deep, at `(18, 61..63, 18)` with a `stone_bricks` rim. Water spawn points: basin center.
- Mob spawn ring: 16 points at radius 27, each a `mossy_cobblestone` marker block in the floor. `ArenaLayout.mobSpawns` = the block above each marker.
- Light: `glowstone` under the floor every 6 blocks is not needed (time is noon, sky light). Add `sea_lantern` in the pillars for looks only.
- Bounds: `AABB` of the barrier box (radius 32, `y 62..91`). T7 uses it.
- Chunks: radius 32 -> chunks `-3..2` in x and z. Force-load them during `ARENA` (`level.setChunkForced(x, z, true)` [V]) and unforce before delete.

### Template file (`config/mob-arena/arenas/<name>.nbt`)
- Name: `ctx.config().arenaTemplate()` (T2 `MobArenaConfig.Snapshot`, one per phase; read it in `onEnter(WAVE_CONFIG)`). Do not read the editable `MobArenaConfig` model.
- Load: `NbtIo.readCompressed(path, NbtAccounter.unlimitedHeap())`, then `DataFixTypes.STRUCTURE.updateToCurrentVersion(server.getFixerUpper(), tag, NbtUtils.getDataVersion(tag, 500))`, then `new StructureTemplate().load(level.registryAccess().lookupOrThrow(Registries.BLOCK), tag)` [V all names].
- Paste: `template.placeInWorld(level, origin, origin, new StructurePlaceSettings().setIgnoreEntities(false), level.getRandom(), Block.UPDATE_CLIENTS)` [V signature].
- Markers: structure blocks in DATA mode. Metadata `mobarena:team_spawn`, `mobarena:mob_spawn`, `mobarena:water_spawn`. Find them with `template.filterBlocks(origin, settings, Blocks.STRUCTURE_BLOCK)` [V], read the `metadata` NBT, then set the block to air.
- Bounds: from `template.getSize()`. Validation: exactly 1 team spawn and at least 1 mob spawn, else log an error and use the default arena.
